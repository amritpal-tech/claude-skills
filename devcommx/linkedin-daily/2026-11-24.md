Your old HubSpot functions have a shutdown date: February 1.

HubSpot's developer changelog set three dates for design manager serverless functions and Node.js 20 custom code actions.

The trap: the migrated function is a new function. Every form, script and workflow that called the old endpoint has to be pointed at the new one.

Save this before your next HubSpot audit.

The decision underneath it: agents are moving from software features to members of staff, and staff need an owner, a scope and a record.

I'd hold an agent to the same standard as a new hire with system access.

Four things I'd ask every leadership team to put in place this quarter:

1. An agent register. Every agent that touches customer or revenue data, with a named human owner.
2. A scope for each one: which systems, which records, read or write.
3. Approval thresholds, in money or in risk, above which a person signs.
4. An audit trail someone actually reviews, and a date to review or retire the agent.

The executives in that survey are willing. What they're asking for first is control.

The companies that scale agents will be the ones that can show who approved what.

Save this before your next board discussion on AI.
